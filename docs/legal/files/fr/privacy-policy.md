# Politique de confidentialité

Cette traduction est fournie pour votre commodité. Seul le texte anglais fait foi.

En vigueur depuis le 16 octobre 2026

## Résumé

MigraTrack conserve vos données sur votre iPhone et votre Apple Watch. Nous ne collectons, ne recevons et ne vendons pas vos données.

L’app n’a ni compte ni serveur. Elle ne contient ni outil d’analyse ni publicité.

MigraTrack est développée par Ira Babayed.

## Données sur votre iPhone

L’app enregistre votre profil de référence, votre nom si vous le saisissez et les crises que vous notez. Le profil de référence contient vos diagnostics, vos déclencheurs, vos médicaments et l’intensité habituelle de votre douleur.

Ces données restent dans une base de données de l’app sur votre iPhone. Elles y restent jusqu’à ce que vous les supprimiez dans l’app ou que vous supprimiez l’app.

## Apple Santé

Avec votre autorisation, l’app lit votre sommeil dans l’app Santé pour afficher le sommeil de la nuit dernière. L’app n’écrit rien dans l’app Santé.

Les données de sommeil ne quittent pas votre iPhone. Vous pouvez retirer l’autorisation dans l’app Santé à tout moment.

## Apple Watch

Votre iPhone envoie vos crises récentes et vos réglages de saisie à votre Apple Watch jumelée. La montre envoie à votre iPhone les crises que vous notez sur la montre.

Ces données passent directement entre vos propres appareils par WatchConnectivity d’Apple.

## Sauvegardes

Une sauvegarde iCloud ou sur ordinateur de votre iPhone peut contenir les données de MigraTrack. Les réglages de votre compte Apple contrôlent ces sauvegardes.

## Rapports que vous partagez

Un rapport PDF ou Excel quitte l’app uniquement quand vous le partagez depuis la feuille de partage. Vous choisissez le destinataire.

## Supprimer vos données

Réglages › Supprimer toutes les données supprime définitivement toutes les données de MigraTrack sur cet iPhone. Quand vous supprimez l’app, ses données sont aussi supprimées.

## Modifications

Si cette politique change, la nouvelle version s’affiche dans l’app avec une nouvelle date d’entrée en vigueur.
